# AI CodeGen MCP Server

## Tools

| Tool | Description |
|------|-------------|
| `index` | 索引代码库，构建知识图谱 |
| `search` | 搜索符号/文件/内容/依赖 |
| `inspect` | 查看文件或符号详情 |
| `prd` | PRD 生命周期管理 |
| `task` | 任务管理 |
| `verify` | 代码验证 |
| `context` | 获取实现上下文 |

## Running

```bash
python -m ai_codegen.mcp_server.server --workspace /path/to/project
```
