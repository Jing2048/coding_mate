# 算法对抗验证结果：与行业/文献最佳实践对标

> 复现：`cd golf-mate/algo && python -m golfmate_algo.bench.harness`
> 回归锁定：`pytest tests/test_adversarial.py`

## 1. 验证方法论

不做「跑通即完成」，而是**同一真值下多算法对抗**：

| 要素 | 做法 |
|------|------|
| 真值 | 解析速度剖面（高斯基）驱动的倾斜平面圆周挥杆，角度/角速度/角加速度**全闭式**，加速度与位置二阶一致（UT 断言 < 0.5 m/s²） |
| 传感器 | 完整误差模型：ARW/VRW、常值零偏 + 随机游走、标度因子、非正交、失准、g 敏感、**饱和**、量化、安装谐振、抖动、丢包 |
| 等级 | `ideal` / `consumer`（BMI270·ICM-42688 级）/ `harsh`（松散手套卡、陀螺 1000°/s 截止、丢包） |
| 场景 | 单杆（~1.9 s）**与** 多杆会话（8 杆 / ~24 s，含静止间隔） |
| 公平性 | 6 轴无法观测航向，故按**全局最优 yaw 投影**对齐后再比误差 |

> **会话生成器必须自洽**：早期版本对姿态做世界系旋转却未同步重力，导致加速度与姿态矛盾，所有用加速度的滤波器被误判为「更差」。修正后结论完全反转。这类自检本身就是验证的一部分。

## 2. 姿态估计：7 种方法对抗

### 2.1 单次挥杆（平均误差，度）

| 算法 | ideal | consumer | harsh |
|------|------:|---------:|------:|
| **gated_adaptive（本项目）** | 1.15 | **3.76** | **11.59** |
| gyro_only | **0.62** | 4.81 | 16.19 |
| gyro_only + rest-bias | 1.21 | 5.32 | 16.85 |
| Madgwick | 3.27 | 5.69 | 15.64 |
| Mahony | 12.96 | 14.07 | 19.51 |
| EKF（自适应量测噪声） | 17.66 | 16.58 | 15.69 |
| Complementary | 18.10 | 19.08 | 23.46 |

**下杆窗口（Top→Impact，动态最剧烈）**：gated 1.06 / 5.83 / 18.08，Complementary 33.2 / 34.1 / 39.3。

### 2.2 多杆会话（24 s，平均误差，度）

| 算法 | consumer | harsh |
|------|---------:|------:|
| **gated_adaptive** | **6.05** | **6.46** |
| Madgwick | 7.92 | 16.85 |
| Mahony | 8.47 | 14.16 |
| EKF | 8.66 | 9.00 |
| Complementary | 10.02 | 20.27 |
| gyro_only | 54.23 | 65.08 |
| gyro_only + rest-bias | 57.03 | 56.87 |

### 2.3 结论（可辩护）

1. **单杆里纯积分几乎无敌**：1.9 s 内陀螺积分误差 < 1°，任何过度自信的加速度修正都是净损失。这与 Sci. Rep. 2024 放弃经典 AHRS、改用「address 定初值 + 陀螺传播」的选择一致。
2. **会话尺度上纯积分崩溃**：零偏 ~1°/s 在 24 s 累积到 50°+，且**一次性零偏标定不够**（随机游走），必须持续有界。
3. **胜负手是门控何时开**：`gated_adaptive` 在两种尺度上都进前二，且对硬件恶化最不敏感（consumer→harsh 仅 +7%，Madgwick +113%）。

## 3. 关键技术贡献：动力学门控

经典门控只看 `|a|−g` 与 `|ω|`。**顶点（Top）是致命反例**：挥杆反向处 ω→0、`|a|` 恰好接近 g，但加速度被切向项 `r·α` 主导——门在最该关的时刻全开。

实测顶点附近：`|ω|=0.08 rad/s`、`|a|=7.4 m/s²`、`|α|=25 rad/s²`。仅用前两者的门控输出 0.51（半开），实测引入 8° 姿态误差。

**做法**：门控加入角加速度项，并收紧尺度：

```
gate = exp(-((|a|-g)/σa)²) · exp(-(|ω|/σw)²) · exp(-(|α|/σα)²)
σa = 0.5 m/s²   σw = 0.8 rad/s   σα = 5 rad/s²
```

再叠加**硬静止确认**：只有 rest 判定为真时才允许倾角修正。这保证了 *挥杆过程中永不劣于纯积分*，同时在会话尺度上界住漂移。UT `test_gate_closes_at_top_where_alpha_peaks` 锁定该行为。

## 4. 轨迹重建：刚性杠杆解 vs 二次积分

### 4.1 方法

腕部传感器可近似为绕缓变旋转中心的刚性偏置点：`p(t) = c + R(t)·L`。二阶微分给出

```
f(t) = ([ω]×[ω]× + [α]×)·L − R(t)ᵀ·g_world
```

**对 L 线性**。最小二乘解出 L 后，轨迹由姿态直接重建，**完全不做二次积分**，因此不累积漂移。

**可观测性**：平面挥杆绕单轴旋转时，沿该轴平移传感器不改变加速度 ⇒ 该分量根本不可观测（法方程奇异）。用**截断 SVD**剔除而非岭回归压制；被剔除分量只造成世界系常值偏移，参考到 address 后自动抵消。`rank` 与零空间方向随结果返回，不静默伪造。

### 4.2 结果（位置误差 cm，平均）

| 方法 | ideal | consumer | harsh |
|------|------:|---------:|------:|
| **lever_arm** | **2.00** | **4.01** | **13.97** |
| dead_reckon + ZUPT | 4.83 | 11.63 | 27.89 |

消费级下 **2.9×** 优于二次积分基线。半径估计误差：ideal 1.2 cm。

> **诚实声明**：合成挥杆满足刚性旋转假设，因此该数字是上界。文献（Sci. Rep. 2024，单腕 IMU，真人）全相位约 **17 cm**。真实腕部有腕铰链与中心平移，残差 `residual_rms_m_s2` 即为假设失效指标，超阈值时管线自动回退到 ZUPT 积分。

## 5. 事件检测

物理定义替代阈值：**Impact = 高通（>40 Hz）加速度瞬态峰**（击球是宽带机械冲击，摆动动力学是低频）；**Top = 主旋转轴投影角速度过零**（运动物理反向，与幅值尺度无关）；Address/Finish = 相对自身峰值的自适应迟滞。

| 事件 | ideal | consumer | harsh |
|------|------:|---------:|------:|
| Address | 0.0 | 7.5 | 26.3 |
| Top | 0.0 | 7.9 | 30.0 |
| Impact | 5.0 | 6.3 | **5.4** |
| Finish | 0.0 | 9.6 | 46.3 |

单位 ms，平均绝对误差。

**对标**：Kim & Park (Sensors 2020) 单 IMU + BLSTM/CNN 关键事件 MAE **5–92 ms**。本方法在 consumer 级全部 ≤ 10 ms，**且无需训练数据**。

**关键设计验证**：早期用「包络相减」找冲击，在 casting（早释放）挥杆上偏差 245 ms——因为下杆早期的向心加速度大包在幅值上压过击球尖峰。换成真正的高通后降到 5 ms。UT `test_impact_detection_survives_accel_clipping` 进一步验证加速度计被 8 g 截止时仍 < 60 ms。

## 6. 对抗与退化测试

`tests/test_adversarial.py` 覆盖：

| 类别 | 断言 |
|------|------|
| 生成器自洽 | 位置二阶差分 ≈ 合成加速度；陀螺积分 ≈ 真值姿态；会话静止段加速度 ≡ 重力 |
| 门控 | 顶点关闭、击球关闭、静止开启 |
| 姿态 | 挥杆内不劣于纯积分；会话内优于纯积分 2× 以上 |
| 轨迹 | 半径恢复、秩=2 且零空间被显式报告、噪声下优于二次积分 |
| 事件 | ideal ≤ 20 ms / consumer ≤ 40 ms 回归预算；加速度饱和仍可定位冲击 |
| 退化 | NaN/Inf 不传播且四元数保持单位；空输入；无运动时显式报错而非返回垃圾；丢包+抖动下管线输出有限 |

## 7. 与行业实践的定位

| 能力 | 行业参考 | 本项目 P0 |
|------|----------|-----------|
| 冲击时刻 | Golfshot Swing ID（Apple 800 Hz 加速度计） | 高通瞬态，consumer 6.3 ms @200 Hz |

## 8. 尚未由仿真关闭的风险

1. 软组织/手套滑动的真实统计（当前用二阶谐振近似）
2. 真实击球冲击的非线性与传感器恢复时间
3. 旋转中心平移导致的刚性假设失效程度
4. 个体解剖差异与左右手
5. 真实磁畸变（P0 默认不用磁强计，故暂不阻塞）

这些必须用小规模真实标定集设闸门。P0 证明的是**算法正确性与相对优劣**，不是**测量完备性**。
